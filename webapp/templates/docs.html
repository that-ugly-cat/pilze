Come si compila un profilo specie

Ogni file profiles/<id>.yaml descrive una specie. Il motore è species-agnostic: cambia solo il profilo. Tutti i valori sono priori esperti — il punto di partenza, non verità assolute.

Come tutto si combina

La predizione di una cella per una specie è:

predizione = idoneità_statica × readiness_dinamica

  • idoneità statica (il dove) = host (gate: niente ospite → 0) × media-geometrica di elevazione, pendenza, esposizione, pH, drenaggio × gate habitat (bosco o prato, secondo il campo habitat).
  • readiness dinamica (il quando) = gate(fenologia, umidità) × media-geometrica di pioggia, temperatura del suolo, shock termico, timing.

I fattori graduati si combinano morbidi (media geometrica): un fattore mediocre abbassa ma non azzera. I gate invece azzerano (host assente, fuori stagione, suolo troppo secco, fuori dall'habitat giusto).

host_genera — l'albero ospite gate

Dizionario classe: peso (peso 0–1). Ogni cella ha un tipo di bosco (dalla carta forestale CFI2020); il suo peso nel profilo è l'affinità della specie con quel tipo. 1.0 = ideale, 0.x = secondario, assente = non ospite (0). Se la cella è micorrizica ma nessun tipo compatibile → idoneità 0.

La legenda completa (codici CFI → classe) è in config/crosswalk.yaml. Il canopy (Sentinel-2) declassa a parte gli ospiti conifera dove la chioma è morta (Vaia/bostrico).

static_envelope — l'ambiente fisico

Fattori graduati (match morbido, nessun salto ai bordi). Un fattore omesso = neutro (non penalizza).

campoforma / valorinote
elevation_m{ min, opt: [a, b], max } trapezoide: 0 sotto min, sale a 1 su [min,a], pieno su [a,b], scende a 0 su [b,max].
slope_deg{ opt: [a, b] } min/max opzionali (margine ~10° se assenti).
aspectwarm · cool · neutral esposizione preferita (S assolato / N fresco / indifferente).
soil_phacidic · neutral · calcareous · tolerant tolerant = va bene su tutti i pH.
drainagewell_drained · moist drenaggio preferito del suolo.

Il gate di copertura (WorldCover, completo) NON sta nel profilo ma dipende da habitat: per le specie di bosco azzera fuori dal bosco, per quelle di prato fuori dal prato. Il canopy (Sentinel-2) declassa a parte le conifere a chioma morta.

phenology_months — quando fruttifica gate

Lista di mesi 1–12, es. [8, 9, 10, 11]. Fuori da questi mesi la readiness è ~0 (con una rampa morbida ai mesi adiacenti, per non spaccare al confine).

dynamic_triggers — le soglie meteo (readiness)

campoforma / valorinote
rain_window_daysintero (es. 15) giorni su cui sommare la pioggia.
cumulative_rain_mmmm (es. 45) pioggia cumulata soglia sulla finestra (pieno a questa, metà ~15 mm sotto).
soil_temp_c{ min, max } °C banda di temperatura del suolo ottimale.
thermal_shock_c°C (es. 5) entità del calo di temperatura del suolo che innesca la buttata.
moisture_floorm³/m³ (es. 0.22) gate sotto questa umidità del suolo la buttata aborta → 0.
lag_days{ opt: [a, b] } giorni ritardo dopo il trigger in cui avviene la buttata. È la finestra «pronto»: prima = in fieri, dentro = pronto, dopo (fino a 2·b) = tardi.

Esempi

Micorrizica di bosco (porcino):

species:
  id: boletus_edulis
  common_name: porcino
  trophic_mode: mycorrhizal

  host_genera:            # solo i tipi in cui fa simbiosi, peso = affinità
    pecceta: 1.0
    faggeta: 0.9
    castagneto: 0.7

  static_envelope:
    elevation_m: { min: 500, opt: [800, 1600], max: 2000 }
    aspect: cool
    slope_deg: { opt: [5, 30] }
    soil_ph: acidic
    drainage: well_drained

  phenology_months: [8, 9, 10, 11]

  dynamic_triggers:
    rain_window_days: 15
    cumulative_rain_mm: 45
    soil_temp_c: { min: 8, max: 18 }
    thermal_shock_c: 5
    lag_days: { opt: [10, 20] }
    moisture_floor: 0.22

Saprotrofo di prato (coprino) — habitat: grassland, senza host_genera:

species:
  id: coprinus_comatus
  common_name: coprino chiomato
  trophic_mode: saprotrophic
  habitat: grassland          # gate = prato (non bosco), niente host_genera
  static_envelope:
    elevation_m: { opt: [0, 1200], max: 1600 }
    drainage: moist
    soil_ph: tolerant
  phenology_months: [5, 6, 9, 10, 11]
  dynamic_triggers:
    rain_window_days: 10
    cumulative_rain_mm: 25
    soil_temp_c: { min: 8, max: 22 }
    lag_days: { opt: [4, 10] }
    moisture_floor: 0.20

Dopo aver salvato

  • Campi statici (host_genera, static_envelope, trophic_mode, habitat) → rigenera le mappe (bottone in Profili).
  • Campi dinamici (dynamic_triggers, phenology_months) → li ricalcola il poller ogni notte, nessuna rigenerazione.
  • common_name → solo visualizzazione.
