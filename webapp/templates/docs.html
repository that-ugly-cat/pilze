Come si compila un profilo specie

Ogni file profiles/<id>.yaml descrive una specie. Il motore è species-agnostic: cambia solo il profilo. Tutti i valori sono priori esperti — il punto di partenza, non verità assolute. I profili vivi si modificano dall'editor (Profili, riservato agli admin).

host_genera — l'albero ospite gate

Dizionario classe: peso (peso 0–1). Ogni cella ha un tipo di bosco (dalla carta forestale CFI2020); il suo peso nel profilo è l'affinità della specie con quel tipo. 1.0 = ideale, 0.x = secondario, assente = non ospite (0). Se la cella è micorrizica e nessun tipo è compatibile → idoneità 0.

host_floor (opzionale, default 0) ammorbidisce quel veto: è quanto vale l'ospite sbagliato. Serve dove la lista è stretta per dottrina ma i ritrovamenti cadono fuori — la CFI dà una categoria per poligono di gestione, e «faggeta» non vuol dire «non c'è un abete». È per specie e non per il motore, perché un pavimento a 0.12 fa salire l'ovolo (+0.433 → +0.688 di Boyce) e crollare il porcino (+0.782 → +0.460): un valore unico pagherebbe l'uno con l'altro. Il valore, però, il Boyce non sa sceglierlo — spinto fino a 0.90 continua a premiare, cioè premia un modello in cui l'ospite non conta: vedi «Perché il pavimento sta nel profilo» nella prima parte. Per questo il default è 0 e nessun profilo lo dichiara. Restano veti secchi il fuori-bosco e la chioma morta (Vaia/bostrico), che sono affermazioni diverse da «qui il bosco è di un altro tipo».

static_envelope — l'ambiente fisico

Fattori graduati (match morbido, nessun salto ai bordi). Un fattore omesso = neutro (non penalizza).

campoforma / valorinote
elevation_m{ min, opt: [a, b], max } trapezoide: 0 sotto min, sale a 1 su [min,a], pieno su [a,b], scende a 0 su [b,max].
slope_deg{ opt: [a, b] } min/max opzionali (margine ~10° se assenti).
aspectwarm · cool · neutral esposizione preferita (S assolato / N fresco / indifferente).
soil_phacidic · neutral · calcareous · tolerant tolerant = va bene su tutti i pH.
drainagewell_drained · moist drenaggio preferito. Misurato dalla posizione topografica (crinale → asciutto, conca piatta → impregnato); dove il terreno è piatto resta «non misurato» e non penalizza.
edge_density{ opt: [a, b] }, frazione 0–1 opt-in: entra nel punteggio solo se lo dichiari. Quota di confine bosco/prato nell'intorno — serve alle specie di margine, invisibili a qualunque frazione di copertura perché il margine è più stretto di un pixel. Ordine di grandezza nell'AOI: mediana 0.05, p90 0.14.

Il gate di copertura (WorldCover, completo) NON sta qui ma in habitat: azzera fuori dalle coperture dichiarate, con gradazione. Il canopy (Sentinel-2) declassa a parte le conifere a chioma morta.

phenology_months — quando fruttifica gate

Lista di mesi 1–12, es. [8, 9, 10, 11]. Fuori da questi mesi la readiness è ~0 (con una rampa morbida ai mesi adiacenti, per non spaccare al confine).

dynamic_triggers — le soglie meteo (readiness)

campoforma / valorinote
rain_window_daysintero (es. 15) giorni su cui sommare la pioggia.
cumulative_rain_mmmm (es. 45) pioggia cumulata soglia sulla finestra (pieno a questa, metà ~15 mm sotto).
soil_temp_c{ min, max } °C banda di temperatura del suolo ottimale.
thermal_shock_c°C (es. 5) entità del calo di temperatura del suolo che innesca la buttata.
moisture_floorm³/m³ (es. 0.22) gate sotto questa umidità del suolo la buttata aborta → 0.
lag_days{ opt: [a, b] } giorni ritardo dopo il trigger in cui avviene la buttata. È la finestra «pronto»: prima = in fieri, dentro = pronto, dopo (fino a 2·b) = tardi.

Esempi

Sono i profili veri, non inventati: un test li rilegge da questa pagina e li passa al validatore, così un esempio non può restare indietro rispetto alle regole.

Micorrizica di bosco (porcino) — l'ospite fa da gate:

species:
  id: boletus_edulis
  common_name: porcino
  trophic_mode: mycorrhizal

  host_genera:            # solo i tipi in cui fa simbiosi, peso = affinità
    pecceta: 1.0
    faggeta: 0.9
    castagneto: 0.7
    # larici_cembreto assente: MAI larice

  static_envelope:
    elevation_m: { min: 500, opt: [800, 1600], max: 2000 }
    aspect: cool
    slope_deg: { opt: [5, 30] }
    soil_ph: acidic
    drainage: moist       # misurato: sta sul piede del versante, non sul crinale

  phenology_months: [8, 9, 10, 11]

  dynamic_triggers:
    rain_window_days: 25  # deve superare lag max, o l'innesco esce dalla finestra
    cumulative_rain_mm: 60
    soil_temp_c: { min: 8, max: 18 }
    thermal_shock_c: 2
    lag_days: { opt: [10, 20] }
    moisture_floor: 0.12

Saprotrofo di ecotono (mazza di tamburo) — niente host_genera, gate di copertura a pesi perché vive sul margine fra bosco e prato:

species:
  id: macrolepiota_procera
  common_name: mazza di tamburo
  trophic_mode: saprotrophic

  habitat:                # né bosco né prato: il confine fra i due
    grassland: 1.0
    forest: 0.7

  static_envelope:
    elevation_m: { min: 0, opt: [300, 1800], max: 2200 }
    slope_deg: { opt: [0, 20], max: 35 }
    aspect: cool
    soil_ph: tolerant
    drainage: well_drained
    edge_density: { min: -0.1, opt: [0.08, 1.0] }   # min negativo: a bordo zero
                                                    # resta una penalità, non un veto

  phenology_months: [7, 8, 9, 10]

  dynamic_triggers:
    rain_window_days: 18
    cumulative_rain_mm: 55
    soil_temp_c: { min: 8, max: 22 }
    thermal_shock_c: 1.5
    lag_days: { opt: [6, 14] }
    moisture_floor: 0.15

Dopo aver salvato

  • Campi statici (host_genera, static_envelope, trophic_mode, habitat) → rigenera le mappe (bottone in Profili).
  • Campi dinamici (dynamic_triggers, phenology_months) → li ricalcola il poller ogni notte, nessuna rigenerazione.
  • common_name → solo visualizzazione.
